# TravelNest Terraform (AWS)

Terraform owns the **cloud infrastructure, the cluster, the platform add-ons,
and the Argo CD bootstrap** for the `aws-prod` environment. First-party
application workloads stay in `deploy/k8s/` and are delivered by Argo CD — this
Terraform tree does not manage them.

```
network  ─▶ EKS ─▶ IAM (IRSA)
   │         │
   │         ├─▶ RDS MySQL        (managed data)
   │         ├─▶ ElastiCache Redis (managed data)
   │         └─▶ S3 media bucket
   ├─▶ Route53 zone
   └─▶ addons: Argo CD, Traefik, cert-manager, external-dns,
               metrics-server, cluster-autoscaler (+ optional monitoring)
```

## Layout

| Path | Purpose |
|---|---|
| `bootstrap/` | Creates the S3 state bucket + DynamoDB lock table. Local state; run once. |
| `modules/network` | VPC, subnets, NAT, VPC endpoints. |
| `modules/eks` | EKS cluster, managed node group, OIDC/IRSA, EBS CSI add-on. |
| `modules/iam` | IRSA roles (cert-manager, external-dns, cluster-autoscaler) + app S3 user. |
| `modules/rds` | RDS MySQL 8.0 (password managed by Secrets Manager). |
| `modules/elasticache` | ElastiCache Redis 7. |
| `modules/s3` | Media bucket (versioned, encrypted, private). |
| `modules/dns` | Route53 hosted zone (create or look up). |
| `modules/addons` | Default `gp3` StorageClass + Helm releases for the platform. |
| `environments/aws-prod` | Composes the modules; a single `terraform apply` builds the cluster and installs the platform. |

Helm **values only** live in `../helm/platform/<chart>/values-aws-prod.yaml`.

## Prerequisites

- Terraform >= 1.6, AWS credentials with admin rights for the target account.
- `kubectl` (for post-apply steps).
- The SOPS age key on disk (`deploy/k8s/.age/keys.txt`) for the secret handoff.

## 1. Bootstrap remote state (once)

```bash
cd deploy/terraform/bootstrap
terraform init
terraform apply -var 'aws_region=ap-southeast-1'
# note the outputs
```

Copy the resulting bucket/table into a local backend config:

```bash
cd ../environments/aws-prod
cp backend.hcl.example backend.hcl   # edit with the bootstrap outputs
terraform init -backend-config=backend.hcl
```

## 2. Apply the environment

```bash
# Review first.
terraform plan  -var-file=aws-prod.tfvars
terraform apply -var-file=aws-prod.tfvars
```

This creates the VPC, EKS cluster, RDS, ElastiCache, S3, Route53 zone, IRSA
roles, and installs Traefik, Argo CD (with KSOPS baked in), cert-manager,
external-dns, metrics-server, and cluster-autoscaler.

Point kubectl at the cluster:

```bash
aws eks update-kubeconfig --region ap-southeast-1 --name travelnest-prod
```

## 3. Route53 delegation

If `create_hosted_zone = true`, point your registrar at the zone's NS records:

```bash
terraform output route53_name_servers
```

external-dns then creates `deployserver.work` + `*.deployserver.work` from the
Traefik NLB. cert-manager's `letsencrypt-prod` ClusterIssuer issues the
per-Ingress certificates via Route53 DNS-01.

## 4. Hand the managed endpoints to the app (SOPS)

Terraform outputs the values the app needs. Put them into
`deploy/k8s/.env.prod` and re-seal:

```bash
terraform output -json env_prod_hint
# RDS master password (managed in Secrets Manager):
aws secretsmanager get-secret-value \
  --secret-id "$(terraform output -raw db_master_user_secret_arn)" \
  --query SecretString --output text | jq -r .password
# S3 user keys (sensitive):
terraform output -raw s3_access_key_id
terraform output -raw s3_secret_access_key

cd ../../.. # deploy/
$EDITOR k8s/.env.prod
./scripts/secrets/seal-prod-secrets.sh
git add 'k8s/**/secret.enc.yaml' && git commit -m "chore(secrets): point prod at managed data"
```

## 5. Create the KSOPS age key in the cluster

Argo CD's repo-server needs the `sops-age` Secret to decrypt `secret.enc.yaml`:

```bash
kubectl -n argocd create secret generic sops-age \
  --from-file=keys.txt=deploy/k8s/.age/keys.txt
kubectl -n argocd rollout restart deploy/argo-cd-argocd-repo-server
```

The root Application is applied by Terraform (`kubectl_manifest`) and syncs
`deploy/k8s/environments/prod`. Child Applications retry until the age key is
present.

## Notes

- **KSOPS is baked into the Argo CD Helm values** so no post-install patch is
  needed on this cluster. The manual `deploy/k8s/bootstrap/argocd/ksops/`
  manifests remain for k3d/VPS installs.
- **The age key is never stored in Terraform state.** It is created out of band.
- **RDS password** is generated by RDS (`manage_master_user_password = true`) and
  lives in AWS Secrets Manager; retrieve it once for the SOPS handoff.
- **Keycloak database:** the RDS instance creates the `travelnest` database. The
  `keycloak` database is created by a PreSync Job in
  `deploy/k8s/infra/keycloak/overlays/prod/` because RDS cannot run the old
  in-cluster init ConfigMap.
- **Redis is not TLS by default** (`transit_encryption_enabled = false`) to match
  the current application client; enable it once the app uses `rediss://`.
- **NLB provisioning:** Traefik requests an NLB via the in-tree AWS cloud
  provider annotation. If your EKS version no longer provisions it, install the
  AWS Load Balancer Controller and switch the annotation to
  `service.beta.kubernetes.io/aws-load-balancer-type: external`.
- **Least privilege:** the app connects to RDS as the master user. Create a
  scoped application user and move it into the SOPS secret as a follow-up.
- **The Node `minio` client now reads `MINIO_REGION`**; without it, presigned
  URLs are signed for `us-east-1`.
